# Воспроизведение новой проверки

Для работы приложения тренировочный набор и PyTorch не нужны. Эта инструкция для повторения обучения/измерений. Источники FER2013, pinned revision и SHA-256: reports/reliability/benchmark_sources.json. Используется публичное зеркало; условия исходных данных перед новым применением нужно проверить отдельно. В архиве нет заново скачанных изображений FER2013. Старый пользовательский датасет с точками сохранён.

```bash
uv sync --all-packages --group training --no-dev --python 3.12 --locked
uv run --no-sync python tools/fetch_quality_benchmark.py --include-train
uv run --no-sync python tools/benchmark_quality.py public
uv run --no-sync python tools/train_reliable_head.py
uv run --no-sync python tools/benchmark_quality.py public
uv run --no-sync python tools/benchmark_quality.py private
```

Рабочая папка по умолчанию datasets/fer2013_benchmark, можно изменить через EMO_BENCHMARK_DIR. Скрипты benchmark/head используют CPU, два потока; основной ноутбук продолжает поддерживать auto CPU/CUDA/MPS. Выделение признаков занимает несколько минут. Оно кэшируется, при изменении данных/основы сети кэш надо удалить и пересчитать. Первые два public-запуска — разработка; private выполняется только после фиксации модели/порогов. В предоставленном архиве кандидат последнего слоя уже включён: public может сравнить его без повторного обучения. Экспериментальные веса не становятся default автоматически.

Репликация: исходная HSEmotion EfficientNet-B0, фиксированные feature-extractor и BatchNorm. Выбрано до 700 уникальных train-картинок на класс. Исключены точные дубликаты, совпадения с PublicTest и выбранные изображения с конфликтующими метками. Для train используются исходное/зеркальное представления. Только linear-head обучается 200 шагов, CE + distillation KL с temperature=2. Силы distillation .25/1/4, checkpoints 50/100/200 сравниваются на selection subset; лучшая конфигурация выбирается там же. Ни PrivateTest, ни подмножества для калибровки/порогов в head-оптимизацию не входят. Во время разработки PublicTest уже просматривался: он не является независимым итоговым тестом.

PublicTest очищен от точных повторов и разбит стратифицированно с фиксированными seed на selection, temperature-calibration и policy-fit. Настройка T минимизирует NLL. Предсказания обычного и зеркального кропа усредняются в logits, затем temperature/softmax. Политика отказывается при несовпадении классов этих двух видов, низком score/малом margin или неподтверждённом contempt. Порог выбирается по максимальному покрытию при достаточно хорошем Wilson lower bound; целевые 90% не являются гарантией. Вся конфигурация frozen_policy фиксируется до PrivateTest.

Для PrivateTest удалены точные совпадения с PublicTest/выбранными train-изображениями и повторы внутри split. Оценены все сохранённые строки, включая отсутствие детекции как отказ. Сравнение raw-моделей и selective-режима разделено; точность среди ответов всегда сопровождается coverage. Субъектных ID у зеркала нет: это image-level, а не доказательство обобщения на совершенно новых людях. Пересечение с исходным pretraining неизвестно, около-дубликаты не исключены.

FER2013 содержит 48×48 чёрно-белые кропы. Для этого протокола они увеличены до 256×256, JPEG quality=95, затем снова пропущены через тот же YuNet и prepare_face, что и сервис. Увеличение не создаёт новых деталей. Это отдельный домен; результат нельзя автоматически переносить на цветное видео, профили, перекрытые/маленькие лица или все демографические группы.

Результаты, logits и SHA-256 политики: reports/reliability. Перепроверка экспорта: training.json кандидата. Новый стандарт запуска требует полного каталога models/emotion_reliable (ONNX, metadata, policy) и models/checksums.json. Несовпадение весов/политики вызывает явную ошибку. Старые четыре режима оставлены для исследований. Не меняйте metadata crop у старых весов ради включения нового режима.
