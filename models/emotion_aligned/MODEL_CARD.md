# Экспериментальная модель с выравниванием по пяти точкам

EfficientNet-B0, исходные HSEmotion enet_b0_8_best_afew, 8 выходов, RGB 224×224, ImageNet-нормализация, logits. Координаты YuNet используются для similarity-выравнивания `yunet5_similarity_v1`; они не добавляются к вектору входов сети. Порядок точек: right_eye, left_eye, nose, right_mouth, left_mouth. Общая реализация: common/face_preprocessing.py.

Полное обучение: 794 train / 183 validation, seed 42, 2 эпохи головы и 3 всей сети. Лучшей по validation macro-F1 оказалась эпоха 4. Исходный aligned macro-F1: 0.536742; выбранный: 0.544039. Парный bbox-запуск на тех же строках: 0.486668, лучшая эпоха 0 (исходные веса). Подробные отчёты: reports/landmark_validation.

Это экспериментальный кандидат, не доказанное улучшение на новых людях. Test не оценивался в этом сравнении; старый test ранее просматривался. Метки унаследованы от видео, contempt/fear/sadness отсутствуют в ground-truth. Оценки softmax не калиброваны и не определяют внутреннее состояние человека. Шаблон выравнивания фиксирован, его оптимальность не доказана.

Происхождение pretrained: https://github.com/av-savchenko/face-emotion-recognition . Проверяйте условия исходных моделей и датасетов перед дальнейшим распространением/применением. Исходные лицевые кадры не были опубликованы на GitHub в ходе этой работы.

Запуск: `uv run --no-sync python tools/project.py start --model aligned`. По умолчанию сохранена прежняя bbox-модель. Старые сообщения без точек нельзя использовать для проверки aligned: загрузите новое видео.
