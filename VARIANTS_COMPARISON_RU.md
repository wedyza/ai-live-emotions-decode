# Сводка: вариант 1 и вариант 2

## Что называется вариантами

**Вариант 1** — сделанная ранее архитектура: точки помогают выровнять лицо, а классификатор получает только изображение. В ней сохранены прежние профили reliable/expanded. Для контролируемого сравнения взят последний image-only классификатор expanded из models/emotion_consensus; команда --model variant1 является его явным псевдонимом. Более осторожный старый reliable остаётся default и не подменяется.

**Вариант 2** — та же фотографическая часть плюс отдельный обученный вход с координатами. Полный ONNX принимает два тензора, это не только переименование выравнивания. Новые веса в models/emotion_variant2, команда --model variant2.

## Разница в устройстве

| Свойство | Вариант 1 | Вариант 2 |
|---|---|---|
| Исходные данные | Фото и пять точек YuNet | Те же фото и точки |
| Для чего точки | Выравнивание фотографии | Выравнивание и отдельные числовые признаки |
| Вход ONNX | input: float32 [1,3,224,224] | image: float32 [1,3,224,224] + landmarks: float32 [1,10] |
| Фотографические признаки | EfficientNet-B0, 1280 | Та же основа и тот же классификатор фотографии |
| Ветвь координат | Отсутствует | MLP 10→32→16, SiLU |
| Объединение | 1280 признаков | Конкатенация 1280+16=1296 |
| Выход | Восемь logits, затем политика принятия/отказа | Восемь logits, затем политика принятия/отказа |
| При отсутствии точек | Aligned-обработка не может подтвердить выражение | Явный uncertain, без нулей/шаблона вместо входа |
| Новый код runtime | Прежние LocalEmotionModel/ReliableEmotionModel | LocalFusionModel/ReliableFusionModel |

В варианте 2 фотографическая матрица классификатора и bias заморожены и совпадают с вариантом 1; обучаются MLP геометрии и соответствующий блок итоговой матрицы. Это эквивалентно добавочной геометрической поправке к logits. Такой контролируемый эксперимент проверяет именно добавление координат, без одновременного переобучения всей CNN. Вариант с совместным размораживанием всех частей не заявляется проверенным.

## Какие координаты поступают

Пять точек: right_eye, left_eye, nose, right_mouth, left_mouth. Используются реальные координаты из полного кадра ДО выравнивания. Начало координат — середина глаз, единица масштаба — расстояние между ними, горизонтальная ось — линия глаз. Это убирает перенос, поворот и равномерный масштаб.

Получаются десять float32. Положение глаз в этой системе фиксировано (-0.5,0) и (0.5,0); оставшиеся шесть компонент описывают нос и уголки рта. Поэтому речь не о десяти независимых измерениях выражения. Внутри ONNX выполняется дополнительная стандартизация по mean/std, вычисленным только на train. Снаружи повторно её применять не надо.

При отражении фото отражаются и координаты, а пары глаз/уголков рта меняются местами. Одна общая реализация используется при подготовке данных, обучении и в сервисе: libs/common/src/common/landmark_features.py. Постоянный canonical template, который нужен для выравнивания изображения, не подаётся вместо реальных координат.

## Что обучено и как проверено

Источник — уже проверенные FER+ голосования, strong consensus >=6/10. Те же train/selection/calibration/policy, что у последнего image-only эксперимента. CNN и фото-head не менялись. Фото-head варианта 1 ранее обучен на3280 найденных изображениях; геометрическая ветвь использовала3279 из них: один набор точек не прошёл проверку правдоподобия. Это отмечено, а не скрыто как полностью одинаковое обучение с нуля.

MLP обучен по мягким распределениям голосов. Проверены 200/500 шагов и штраф геометрической поправки 0/.1/1. Победил шаг200 без штрафа. Selection macro-F1: вариант1 0.86191, вариант2 0.87080. Максимальный модуль веса обученной геометрической проекции0.13618; ветвь не осталась нулевой.

Дополнительно обучен контроль той же геометрической ветви с постоянным средним входом. Он может учить только общую поправку, без различий координат между лицами. Так можно отличить пользу самих точек от пользы дополнительных смещений классов. Это исследовательский контроль, не третий пользовательский вариант.

Для итогового сравнения выделено750 других strong-consensus снимков, не входивших в предыдущие адаптации, просмотренные контрольные части или текущий train. Пять распространённых классов по150: anger/happiness/neutral/sadness/surprise. Лица найдены на744, на шести не найдены; сравнение классификаторов выполнено на одинаковых744. Страх/отвращение/презрение на этой новой части проверить нельзя: свежих неиспользованных примеров не осталось. Идентификаторов людей нет, пересечение с исходным HSEmotion pretraining неизвестно.

Все веса, параметры калибровки и пороги варианта2 зафиксированы до оценки этой части; после теста не подбирались. Старые метрики на804/3464 других снимках напрямую с этим тестом не сравниваются.

## Результаты на одном новом контроле

| Измерение | Вариант 1 | Вариант 2 |
|---|---:|---:|
| Без отказов: совпадений/найденных лиц | 658/744 | 656/744 |
| Без отказов: accuracy | **88.44%** | 88.17% |
| С политикой отказов: ответов | 674/750 | 673/750 |
| С политикой отказов: правильных ответов | 616 | 617 |
| Ошибок среди выданных ответов | 58 | 56 |
| Точность среди выданных ответов | 91.39% | 91.68% |
| Покрытие всех750 снимков | 89.87% | 89.73% |

Разница raw accuracy вариант2−вариант1: **−0.27п.п.**, paired image bootstrap95% CI **[−1.21,+0.67]п.п.**. Статистически убедительного преимущества не получено. Малое улучшение процента среди принятых ответов также не объявляется доказанным преимуществом: принятые подмножества различаются и один ответ дополнительно отклонён.

Контроль с постоянными координатами: 657/744 =88.31%. Вариант2 его также убедительно не превосходит (CI разницы включает0). При случайном перемешивании координат между лицами средняя accuracy варианта2 по20 перестановкам88.05% (диапазон87.63–88.58%). Это согласуется с небольшим вкладом пяти точек в этом эксперименте, но не доказывает бесполезность любой геометрической модели.

**Вывод: вариант2 реализован и использует координаты, но его превосходство здесь не установлено.** Для практического выбора рекомендовать его вместо варианта1 по этим данным нельзя. Он сохранён отдельным экспериментальным режимом, существующий default reliable не менялся. Пять точек не описывают брови, раскрытие век и форму/раскрытие рта подробно; другая геометрия или совместное обучение могут дать иной результат, но не проверены и не обещаются.

## Доказательство двух входов и тесты

- Фактические ONNX inputs: image[1,3,224,224], landmarks[1,10]. Входы проверяются по именам, форме и dtype.
- На20 реальных selection-изображениях /40 видах ONNX совпал с обученным head на тех же признаках: max abs logits difference5.25e-6; решения совпали20/20.
- Изменение только координат при неизменной фотографии меняло logits до0.13058. Это подтверждает использование числового входа, а не его декоративное наличие. Это не13% точности.
- Пропуск координат вызывает явный отказ/ошибку входа. Фото-only fallback или постоянные нули не используются.
- 36 unittest прошли: прежняя совместимость, нормализация, инвариантность, отражение с перестановкой пар, фактическая передача координат анализатором, два реальных ONNX входа, отсутствие fallback и остальные проверки.
- Реальный кадр прошёл YuNet→Face с точками→нормализация→оба входа ONNX→уведомление. Транспорт/хранилище в памяти, НЕ полный Docker-тест.
- На известном снимке с улыбкой новый режим дал happiness; это отдельный регрессионный пример, не независимая accuracy.

Windows/macOS/MPS, полный Docker/HTTP/очереди здесь не проверены. Телеметрия ONNX Runtime остаётся отключённой. Метки описывают видимые выражения, не устанавливают внутреннее настроение человека. Никаких Git commit/push.

## Запуск двух вариантов

Распакуйте проект отдельно от старого. Установка обычного runtime:

```bash
uv sync --all-packages --no-dev --python 3.12 --locked
uv run --no-sync python tools/project.py check --model variant1
uv run --no-sync python tools/project.py check --model variant2
```

Для видео, после tools/project.py infra, запускайте ОДИН вариант за раз:

```bash
uv run --no-sync python tools/project.py start --model variant1
```

Либо, остановив его Ctrl+C:

```bash
uv run --no-sync python tools/project.py start --model variant2
```

Фото без Docker:

```bash
uv run --no-sync python tools/predict_image.py path/to/photo.jpg --mode variant1 --output result1.png
uv run --no-sync python tools/predict_image.py path/to/photo.jpg --mode variant2 --output result2.png
```

Без указания варианта у project.py сохранён прежний reliable. --model variant1 соответствует expanded, выбранному для одинаковой фотографической основы в сравнении. Это различие профиля и архитектуры важно: прежний более консервативный reliable тоже относится к архитектуре варианта1, но его проценты на иных данных нельзя подставлять в эту таблицу.

```bash
uv sync --all-packages --group training --no-dev --python 3.12 --locked
uv run --no-sync python tools/fetch_consensus_data.py
uv run --no-sync python tools/variant2_prepare.py
uv run --no-sync python tools/variant2_cache.py
uv run --no-sync python tools/variant2_train.py
uv run --no-sync python tools/variant2_check_export.py
uv run --no-sync python tools/variant2_evaluate.py
```

Рабочая папка datasets/variant2_experiment (EMO_VARIANT2_DIR), источники из EMO_BENCHMARK_DIR/EMO_CONSENSUS_DIR как в прежней инструкции. Изображения FER+ и большие кэши в архив не включены; скачивание источников проверяется по SHA-256. Готовые ONNX включены, обычный запуск не требует PyTorch или этих датасетов. Скрипты нового обучения не заменяют комплектные веса и не выполняют Git-действий.

Исследовательский test после публикации уже просмотрен. Для дальнейшего подбора нужен другой контроль, а не повторное объявление этих750 изображений независимыми. Субъектная независимость, произвольное видео, редкие классы и отсутствие пересечения с pretraining не установлены.

Ключевые файлы: common/landmark_features.py; tools/variant2_arch.py; ai_service/fusion_emotion_model.py; models/emotion_variant2; reports/variants/*.json. Сохранность предыдущих весов/metadata/policy image-only и default проверена по предыдущему архиву: reports/variants/variant1_preserved.json.

Уверенность высокая в реализации двух входов и выполненных измерениях; прирост качества от пяти точек как отдельных признаков не подтверждён.
