# Разные эксперименты

reliability/ — текущий режим reliable: внешний FER2013, новый head, разделённые selection/calibration/policy и фиксированный PrivateTest. Основной отчёт — RELIABILITY_REPORT_RU.md.

landmark_validation/ — предыдущий эксперимент bbox/aligned на слабых пользовательских видео-метках. experiment_summary.json в корне — ещё более ранняя оценка пользовательского bbox-файнтюнинга. Эти наборы и протоколы различаются; цифры между ними напрямую сравнивать нельзя. Исторические материалы сохранены для воспроизводимости, не являются результатами нового default.
