# Результаты улучшения программы

## Что изменено

Добавлен режим reliable и выбран по умолчанию. У EfficientNet-B0 зафиксированы backbone/BatchNorm, отдельно дообучен последний линейный слой. Подготовка по пяти точкам YuNet одна и та же при обучении и в сервисе. Для обучения использованы FER2013 train, а не старые слабые видео-метки. Из 4568 выбранных уникальных изображений детектор нашёл 4521, ещё 11 выбранных снимков с конфликтующими метками исключены: фактически 4510 лиц, по два представления (обычное/зеркальное).

При обучении head оптимизируются CE и KL-distillation к исходной сети. Это ограничивает потерю ранее выученного; не гарантирует её отсутствия. Лучшие настройки на selection: 200 шагов AdamW, distillation=0.25. Macro-F1 selection: 0.521906 у исходной aligned-сети → 0.598635 у нового head. Это данные разработки, не независимая итоговая оценка.

## Разделение и итоговая проверка

Взято публичное зеркало FER2013, pinned revision и SHA-256 записаны в reports/reliability/benchmark_sources.json. Каждый файл проверяется по хешу. Из PublicTest удалены точные дубликаты: 3563 изображения, разбитые на selection=1425, temperature-calibration=1069, policy-fit=1069 с фиксированными seed. Сравнены пять вариантов. Head не оптимизируется по calibration/policy или PrivateTest.

Окончательные веса, температура и пороги зафиксированы до просмотра метрик PrivateTest. В PrivateTest после исключения точных дубликатов с PublicTest, выбранными train-изображениями и внутри split осталось 3464 из 3589 снимков. По ним НЕ менялись веса или пороги. SHA-256 замороженной политики: 113e1f2f04f03935168ad57acebc2316ff2511a02dd37952bbf479d70398d5a5. В тесте нет разметки contempt, поэтому этот класс не подтверждается и в reliable приводит к отказу.

| Режим | Совпадений среди выданных ответов | Доля всех снимков с ответом | Ошибочных ответов |
|---|---:|---:|---:|
| Прежняя дообученная bbox | 39.95% | 98.56% | 2050 |
| Прежняя дообученная aligned | 35.56% | 98.56% | 2200 |
| Исходная сеть + выравнивание | 56.44% | 98.56% | 1487 |
| Новый последний слой, без отказов | 64.24% | 98.56% | 1221 |
| Новый reliable: TTA + калибровка + отказы | 91.22% | 30.92% | 94 |

Для reliable: 1071 ответ, 977 совпадений, 94 ошибки; на остальных 2393 снимках отказ, включая отсутствие лица. 95% Wilson-интервал точности среди ответов: 89.38–92.77%. Отказы не считаются правильными ответами. На ВСЕХ тестовых снимках доля правильных категорических ответов reliable составляет только 28.20%. Поэтому говорить «точность 91% на всех кадрах» неверно.

Сравнение эффекта самого head на одинаковых 3414 найденных лицах: улучшение accuracy относительно исходной aligned-сети +7.79 п.п., image-level bootstrap 95% CI [+6.36, +9.20] п.п. Не все изменения полезны: усреднение обычного/зеркального logits без отказов даёт 64.15%, слегка ниже 64.24% одного вида. Оно оставлено в составе выбранной заранее политики; тестом не перенастраивалось.

## Качество по классам неодинаково

Ниже precision: если reliable выдал именно этот класс, сколько таких ответов совпали с меткой. Это не полнота обнаружения соответствующей эмоции.

| Выданный класс | Совпадений/ответов | Precision |
|---|---:|---:|
| anger | 87/99 | 87.9% |
| disgust | 9/20 | 45.0% |
| fear | 29/32 | 90.6% |
| happiness | 583/603 | 96.7% |
| neutral | 72/83 | 86.7% |
| sadness | 58/78 | 74.4% |
| surprise | 139/156 | 89.1% |

Слабые места нельзя скрывать за общими 91.22%: disgust — лишь 9/20, sadness — 58/78. Для disgust выборка мала; утверждать его надёжность нельзя. Среди всех 513 тестовых снимков с меткой fear reliable ответил только на 60 и правильно назвал fear на 29. Значительная часть среднего результата обеспечивается happiness. Программа пока НЕ решает задачу надёжного распознавания всех выражений.

## Как действует отказ

Новый head вычисляет logits для обычного и зеркального кропов. Logits усредняются; применяется T=1.030890 и softmax. Для принятия нужны совпадение top-класса двух видов, max score >=0.75, margin >=0, проверяемый класс. Иначе возвращается uncertain с причиной. Температура найдена на отдельной calibration-части: NLL 0.989317 → 0.988957, улучшение небольшое. Калибровка не делает плохой классификатор правильным.

Порог выбрали по policy-fit, с заранее заданной сеткой и критерием покрытия/нижней границы Wilson, не по PrivateTest. Целевые 90% — цель настройки, не гарантия для каждого кадра, класса или нового видео. Ошибки с высокой оценкой остаются возможными. Отсутствующие/некорректные точки приводят к явному uncertain, а не подмене подготовки bbox-кропом. Гипотеза не выводится как распознанная эмоция при отказе.

## Проверки исполнения

- 22 автоматических теста прошли на Linux/Python 3.12. Проверены исходная совместимость, блокировка YuNet, точки, shared preprocessing, softmax/temperature, отказ при неустойчивости, привязка политики к SHA весов, отсутствие неподтверждённого класса в тексте отказа.
- Новый ONNX проверен против PyTorch на 20 реальных selection-изображениях; max abs difference 1.049e-5 при rtol=1e-3/atol=1e-4.
- Реальный полный кадр прошёл YuNet → сообщение с пятью точками → ReliableEmotionModel → уведомление. Транспорт и хранилище в памяти, НЕ Docker-интеграция.
- Повторена прежняя внешняя проба: 209 входов, 215 наблюдений лиц, 54 принятых ответа. Это уже просмотренные снимки без формальных меток, НЕ ещё один независимый accuracy test.
- Три известные проблемные фотографии с видимой улыбкой теперь дали happiness, а не прежние sadness/disgust. В частности astronaut.png: happiness ~99.995%. Это регрессионные примеры, не доказательство общего качества.
- Runtime установлен из обновлённого uv.lock. Добавлен tools/predict_image.py для локального снимка без Docker/датасета. Телеметрия ONNX Runtime отключена до инициализации и через runtime API; прежняя попытка внешнего telemetry-запроса была заблокирована автоматической проверкой, после отключения локальные расчёты завершились.

## Ограничения доказательств

FER2013 — 48×48 чёрно-белые лица с потенциально шумными метками. В этом протоколе они увеличены до 256×256, затем заново пропущены через YuNet и одинаковую подготовку сервиса. Это не создаёт дополнительных деталей и не имитирует полностью реальные цветные видео.

Идентификаторов людей в зеркале нет: исключены точные повторения изображений, но не все около-дубликаты и совпадения людей между split. Возможное пересечение с pretraining HSEmotion неизвестно. Поэтому нельзя обещать измеренный результат на совершенно новых людях или всех демографических группах. Интервалы основаны на изображениях, не группах людей. Метки описывают видимое выражение, а не достоверное внутреннее состояние человека.

Полный Docker/HTTP/очереди, Windows/macOS/MPS/CUDA здесь не проверены. Старые модели и эксперименты сохранены для воспроизводимости, но по умолчанию включён reliable. На GitHub ничего не отправлялось.
